# Functions

Each script contains function used elsewhere in the analysis.

## Important functions

* **balanceMatrix.R**: RAS Balancing matrix method.
* **table_fromTo.R**: Functions to convert a matrix to a flat format, or vice versa.
* **SalesShare.R**: Function to create a sales share trade ratios matrix by using a balanced trade flow matrix as input.
* **futureProduction.R**: Estimates **production by country** based on Trade Ratios matrix and Sales vector.
* **addBatterySize.R**: Adds battery size to production results, to estimate battery requirements by country.
* **ProdAllocationSegments.R**: Allocates future production by segment, using a loop. 
* **Fig_tradeRatios.R**: Display a trade ratios matrix as a heatmap.
* **Fig_Sankey.R**: Create regional **Sankey** figure to showcase main results of vehicle production and sales.
